## How to repeat the check

Each identifier resolves through `https://doi.org/<DOI>`. Machine-readable
metadata for a Crossref-registered item is available at
`https://api.crossref.org/works/<DOI>`, and the same record is mirrored at
`https://api.openalex.org/works/doi:<DOI>`.

The entries added after the first round of checking, numbers 38 to 42, were
resolved the same way.
